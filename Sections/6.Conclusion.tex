\chapter{Conclusions}
\label{ch:conclusion}

This thesis presents PaceANN, a disk-based ANNS system that improves DiskANN-style search without rebuilding the index.
PaceANN combines the Popularity-Adaptive Cache Manager (PAC) with Convergence-Aware Early Termination (CA-ET).
PAC reduces SSD reads by caching frequently visited nodes together with their full-precision vectors, while CA-ET stops easy queries after convergence and avoids unnecessary beam-search expansions.

The evaluation shows that PaceANN improves concurrent-serving throughput over DiskANN and Starling on SPACEV100M, SIFT100M, and DEEP100M under the same memory budget.
The comparison with PipeANN is more dataset-dependent: PaceANN leads on SPACEV100M, while PipeANN is stronger in the high-recall region on SIFT100M and DEEP100M.
The ablation study shows that CA-ET provides the larger share of the improvement, while PAC adds a smaller but consistent gain and supports the convergence signal.

PaceANN still has limitations.
The CA-ET threshold $\theta$ and cache-seeding parameters require calibration for each dataset and environment.
Coordinate co-storage also increases the memory cost of each cached node, reducing the number of nodes that can fit under a fixed budget.
Finally, this thesis does not fully explore query-locality effects or detailed tail-latency behavior across a wider range of concurrency levels.

Future work should automate parameter calibration, adapt cache memory allocation to workload behavior, and evaluate the same stopping principle on other ANN index families.
Overall, PaceANN demonstrates that reducing avoidable SSD I/O during search is an effective and practical way to improve disk-based graph ANNS under concurrent serving.
